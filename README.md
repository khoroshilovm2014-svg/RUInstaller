# RUInstaller

**RUInstaller** — программа для установки приложений на iPhone без App Store.

## Что умеет

- 📱 Установка **MAX** и **ВКонтакте** на iPhone
- 🔐 Вход через **официальный Apple ID**
- 📦 Работа **напрямую с Apple** — данные не передаются третьим лицам
- 🎨 Интерфейс в **стиле Apple** (светлая тема, шрифт Inter)
- 📋 **Журнал операций** — все команды как в командной строке
- 🔧 **Админ-панель** — статистика, управление IPA, техработы
- 📚 **Пошаговое обучение** для новых пользователей

## Установка

1. Скачайте **`RUInstaller-Setup.exe`** из [последнего релиза](../../releases/latest)
2. Запустите установщик
3. Подключите iPhone по USB-кабелю
4. Войдите в свой **Apple ID**
5. Нажмите **«Установить MAX»** или **«Установить ВК»**

## Системные требования

- **Windows 10/11** (64-bit)
- **iPhone** с iOS 14+
- **USB-кабель**
- **Apple ID** (бесплатный)

## Безопасность

- ✅ Все данные передаются **напрямую в Apple**
- ✅ **Не сохраняем** пароли, 2FA-коды
- ✅ **Не передаём** данные третьим лицам
- ✅ Используем **официальные сервисы** Apple
